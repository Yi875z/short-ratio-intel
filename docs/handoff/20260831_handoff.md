## 実データ検証

- 騰落銘柄数: 2026-08-28 プライムで 値上がり873 が日経公表値と**完全一致**。
  値下がりは635で公表631との差4件（0.26%）。分割調整の誤りではなく権利落ち等の
  集計慣行の違いであることを4銘柄すべてで確認済み。
- バックフィル: 245営業日・980レコード・失敗0・スキップ0（2025-08-29〜2026-08-31）。
- レジーム判定: 空売り集計と重なる95営業日で6区分すべてが出現。
  NEUTRAL 54% / ABSORPTION 16% / THIN_MARKET 13% / SELL_PRESSURE 7% /
  BROAD_DE-RISKING 6% / SHORT_COVER 4%。
- 2026-06-04 は空売り比率 40.49% だが市場売買代金が5日平均比 -19.7% のため
  `THIN_MARKET` へ隔離された。素朴な「40%超＝売り圧力」の固定閾値なら誤判定する例。

## 確定した事実（従来「未確認」だったもの）

- **`*_va` 列の単位は百万円**。JPX 空売り集計PDF本文の【単位：百万円】で確認。
- **比率の分母は合計売買代金(d)**。同PDFに (a)/(d)・(b)/(d)・(c)/(d) と明記されており、
  実装の分母は公式定義と一致する。
- 同PDF注記に「数値は外国株券等を含む合計数値」とあり、プライムの騰落銘柄数とは
  母集団が異なることが公式に裏付けられた。
- **J-Quants Light では業種別空売り比率API（`/markets/short-ratio`）が 403**。
  空売り比率の取得元は今後も JPX 公開PDF が正。業種別指数（`/indices/bars/daily`）も 403 のため
  業種別騰落率は nikkei225jp.com のまま。
